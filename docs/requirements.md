# MCP Blog Studio 需求文档

文档版本：1.1；更新：2026-09-30。本文中的产品版本 v0/v1/v2 表示交付阶段，不表示 SDK 的主版本号。

## 1. 目标与使用者

建设中文多人博客，并逐步演进为 Agent 演示项目：先让人能够阅读和管理内容，再通过远程 MCP 管理业务，最后通过 WebMCP 操作当前浏览器页面。

| 用户 | 需求 |
| --- | --- |
| 访客 | 阅读、分类浏览、搜索已发布文章 |
| 作者 | 编辑和发布自己的文章，上传媒体 |
| 管理员 | 管理全部内容、分类、站点和账号 |
| Agent（v1） | 代表持有密钥的用户管理文章，遵循相同权限 |
| 浏览器内 Agent（v2） | 操作当前页面的搜索、筛选、导航和预览状态 |

项目由两位开发者协作。首个远程 MCP 客户端以 Codex 为验收目标。前端采用极简纸面美学，选择性适配模块，保留 Payload 后端；以非商业开源 Demo 方式提供对应源码。

## 2. 版本范围

| 版本 | 产品结果 | 不包含 |
| --- | --- | --- |
| v0 普通博客 | 完整可读写的博客和后台，用户先行验收 | 不暴露 MCP / WebMCP 工具 |
| v1 远程 MCP | Codex 通过 `/mcp` 完成文章管理闭环 | 不通过 MCP 管账号、分类、站点、上传图片或永久删除 |
| v2 WebMCP | 支持的浏览器内可操作页面，并与 v1 配合演示 | 不复制一套数据库业务接口、不把个人 MCP 密钥放到浏览器 |

不做评论、点赞、订阅、站内 AI 聊天、公开注册、中英双语、定时发布。没有单独的演示控制台，先用后台日志与演示脚本展示过程。

## 3. v0 博客模块

| 编号 | 模块 | 必需功能 |
| --- | --- | --- |
| B01 | 首页 | 站点介绍、最新文章、分类入口 |
| B02 | 文章列表 | 封面、标题、摘要、作者、发布日期、分类、分页 |
| B03 | 文章详情 | 富文本正文、图片、链接、标题、引用、列表和代码块 |
| B04 | 分类 | 分类文章页、分页、空状态；管理员维护分类 |
| B05 | 搜索 | 标题/摘要/正文检索，中文、分页、空结果 |
| B06 | 关于页 | 管理员维护站点介绍和关于内容 |
| B07 | 站点体验 | 中文、移动端、导航、页脚、深浅色主题、404 和错误重试 |
| B08 | SEO | 页面元信息、分享信息、站点地图；草稿不索引 |
| B09 | 内容后台 | 草稿、发布、立即编辑、下架、历史版本、回收站和恢复 |
| B10 | 媒体 | JPEG/PNG/WebP，单图不超过 5 MB，封面和正文引用 |
| B11 | 账号 | 管理员创建作者、重置密码、停用账号；不依赖邮件服务 |
| B12 | 日志 | 记录关键文章写入及状态变化，日志不可直接修改 |

## 4. 权限和状态

| 操作 | 访客 | 作者 | 管理员 |
| --- | --- | --- | --- |
| 读取公开文章 | 允许 | 允许 | 允许 |
| 查看草稿、回收站、历史版本 | 禁止 | 自己的文章 | 全部 |
| 创建/编辑/发布/下架/回收/恢复 | 禁止 | 自己的文章 | 全部 |
| 永久删除文章 | 禁止 | 禁止 | 仅后台 |
| 上传/修改/删除媒体 | 禁止 | 自己上传的媒体 | 全部 |
| 管理分类、站点、账号 | 禁止 | 禁止 | 允许 |
| 查看操作日志 | 禁止 | 自己的操作 | 全部 |
| v1 密钥管理 | 禁止 | 创建/撤销自己的密钥 | 另可撤销他人密钥 |

约束：

1. 文章所有者用于权限判断，展示作者独立配置。作者不能通过字段提交变更所有者或角色。
2. 草稿发布后公开；下架或回收后从列表、详情、搜索、站点地图和公开 API 中移除。
3. **已发布文章修改后保存即生效**，不另加审核环节或再次发布步骤。
4. 删除默认进回收站；恢复后一律为草稿；不自动清空回收站。
5. 版本号检查与数据库事务防止旧版本覆盖新修改；冲突要求重新读取并合并。
6. 图片为公开资源，不承载私密附件。当前文章或页面仍引用的图片禁止删除。解除当前引用后允许删除，历史版本可能因此无法再显示该图。
7. 停用账号立即失去受保护操作权限；保留账号记录以维持内容归属及审计链。
8. 后台、REST、GraphQL、预览、Local API 与后续 MCP 必须使用一致权限规则。

## 5. v1 远程 MCP

### 必做模块

| 编号 | 模块 | 要求 |
| --- | --- | --- |
| M01 | 协议接入 | `/mcp`，Streamable HTTP，无状态请求处理，协议协商与关闭由 SDK 处理 |
| M02 | 个人密钥 | 每人独立、可撤销；明文仅创建时显示，服务端保存摘要 |
| M03 | 身份与权限 | 每次请求校验密钥、用户激活状态、当前角色和资源所有权 |
| M04 | 内容业务 | 共用业务层与 Payload 权限，事务、状态迁移、版本冲突 |
| M05 | 查询工具 | 身份、列表、详情、搜索、分类、媒体 |
| M06 | 写入工具 | 创建、修改、发布、下架、回收、恢复 |
| M07 | 格式转换 | MCP Markdown 与 Payload 富文本互转；未知区块不能被静默删除 |
| M08 | 调用审计 | 操作者、工具、目标、结果、错误码；不记录明文密钥和完整正文 |
| M09 | 接入与演示 | Codex 接入说明、端到端脚本、失败和越权演示 |

12 个工具的名称与参数以 [MCP 工具契约](mcp-tools.md) 为准。

新建默认草稿；Agent 可直接发布、下架和回收自己的文章。MCP 不提供永久删除。文章 slug 创建后默认固定，v1 不通过更新工具修改 slug。

### 验收结果

Codex 能完成“读取身份 → 查找分类/媒体 → 创建草稿 → 修改 → 发布 → 读取更新 → 下架 → 回收 → 恢复”。另一作者无法越权；撤销密钥和停用账号生效；冲突和不支持内容得到清晰错误。

## 6. v2 WebMCP

WebMCP 在本项目中负责**页面操作**，v1 MCP 负责**持久化内容业务**。v2 是明确规划的第二个功能版本，仍以兼容性渐进增强的方式上线。

| 编号 | 页面能力 | 预期工具 |
| --- | --- | --- |
| W01 | 搜索/筛选 | `set_search_query`、`filter_posts` |
| W02 | 页面导航 | `open_post`、`open_admin_panel` |
| W03 | 编辑器导航 | `open_post_editor`，只打开有权编辑的文章 |
| W04 | 内容查看 | `preview_post`、`scroll_to_section` |
| W05 | 生命周期 | 随页面挂载注册、卸载清理，执行取消，工具结果与可见 UI 一致 |
| W06 | 降级 | 不支持 WebMCP 时全部普通页面和 v1 MCP 继续工作 |

不在浏览器保存个人 MCP 密钥，不通过 WebMCP 增加发布、删除等持久化写工具。已登录后台用户的预览依旧受服务端权限校验。

### 联合演示

远程 MCP 创建并发布文章；用户打开博客后，浏览器内 Agent 搜索该文章、打开详情、滚动到指定标题。后台编辑/草稿预览演示使用已登录用户会话。两类工具不要求使用同一个 Agent 客户端。

## 7. 部署与非功能要求

- 目标平台：Vercel + Neon PostgreSQL + Vercel Blob，默认域名，免费额度优先。
- 当前云资源未建立，本阶段交付本地运行与部署手册，不声明上线完成。
- 预览与生产隔离，生产使用显式迁移；禁止在生产使用开发 schema push。
- 请求失败不暴露数据库连接、密钥、内部堆栈或他人的草稿信息。
- 本 Demo 首先保证正确性、权限、可恢复及可复现，不承诺高并发生产级 SLA。
- 每个版本必须附测试结果、操作说明、限制及未完成项。
