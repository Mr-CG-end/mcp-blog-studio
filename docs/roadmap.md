# 版本路线与里程碑

日期：2026-09-30。用户已确定 **v1 做 MCP，v2 做 WebMCP**。普通博客作为前置 v0。当前执行 v0，后续仅规划。

## v0：普通博客与用户验收

| 里程碑 | 内容 | 当前状态 | 退出条件 |
| --- | --- | --- | --- |
| V0.1 环境与模型 | 依赖、独立 PostgreSQL、迁移、角色、文章与媒体 | 已实现并完成主要集成验证 | 干净数据库可迁移，服务可启动 |
| V0.2 博客功能 | 首页/列表/详情/分类/搜索/关于、后台、回收站 | 已实现基础布局 | 内容闭环与作者隔离通过 |
| V0.3 视觉与体验 | 接入用户设计模板、移动端、空态、错误态 | Shiro 模块适配已完成，待用户查看 | 用户确认视觉和普通博客功能 |
| V0.4 工程交付 | 文档、测试、初始化说明、本地预览 | 进行中 | 验收记录真实完整，可由另一人复现 |

v0 交付：本地可运行博客、后台账号获取方式、迁移、示例内容、文档。云资源未创建，不将“本地可用”记作“已上线”。

**v1 进入条件：用户明确确认普通博客可以继续扩展 MCP。** Shiro 方案已确认；本地验收不代表云端发布完成。

## v1：远程 MCP

| 里程碑 | 交付 | 验收门槛 |
| --- | --- | --- |
| V1.1 契约与连接 | DTO、schema、模拟服务、`/mcp` SDK 路由、个人密钥与鉴权 | Codex 初始化、工具发现和身份查询成功 |
| V1.2 查询与内容转换 | 6 个读工具、Markdown 转换、安全字段与分页 | 草稿隔离、媒体查询和格式往返通过 |
| V1.3 写入闭环 | 6 个写工具、状态机、并发、创建幂等与审计 | 作者 A 管理自己的内容，作者 B 越权失败 |
| V1.4 真实联调 | Codex 操作脚本、错误与重试演示 | 创建→编辑→发布→下架→回收→恢复完整通过 |
| V1.5 部署验证 | Vercel、Neon、Blob、迁移、HTTPS 与回退 | 云资源准备后实际部署；生产与预览隔离 |

v1 本地验收与云端验收分开记录。没有云资源时可以完成本地工具开发，但不能宣布 v1 线上发布完成。

v1 不做 OAuth 多客户端兼容、MCP 上传、分类管理、永久删除或独立控制台；这些不应混入当前 12 工具范围。

## v2：WebMCP

| 里程碑 | 交付 | 验收门槛 |
| --- | --- | --- |
| V2.1 浏览器可行性 | 支持矩阵、目标浏览器版本、接口核验、feature detection | 真实支持环境能发现最小工具；普通浏览器无回归 |
| V2.2 公开页面工具 | 搜索、筛选、打开文章、滚动 | 工具执行后可见页面状态与返回结果一致 |
| V2.3 后台页面工具 | 打开后台、打开编辑器、权限内预览 | 未登录不访问草稿，作者无法打开他人编辑器 |
| V2.4 生命周期与兼容 | 页面卸载清理、取消、错误、重载和降级 | 无残留工具、重复注册或不可用页面状态 |
| V2.5 联合演示 | 远程 MCP 发文 + WebMCP 页面浏览 | 一套能重复演示的完整脚本与录屏/截图 |

若浏览器试验条件变化，记录具体阻塞和可复现环境。可保留 v1 正常运行，但不能用 mock WebMCP 通过代替真实 Agent 验收。

## 公共门槛

- 每阶段：代码、测试、说明和验收记录同步提交。
- 类型检查、lint、相关单测与集成测试通过；前端变更加浏览器验证。
- 权限、状态或 schema 变更需另一人审查；数据迁移只允许单一负责人合并和执行。
- 免费额度优先，无用户确认不新增付费服务。
- 无待处理的草稿泄露、越权写入、数据覆盖或明文密钥泄露问题。

## 后续候选（不承诺排期）

OAuth 和更多客户端、媒体上传工具、分类管理工具、可观察性增强、细粒度锁与引用表、全文检索升级。评论、订阅和站内 AI 聊天只有新需求确认后才进入路线。
