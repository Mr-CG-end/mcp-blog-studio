| D17 | 免费额度优先、默认域名 | 先展示功能，不自动开通付费；额度按部署时平台信息核验 |

## 需要在对应阶段补齐的外部条件

- 用户提供前端模板，或明确接受当前基础布局。
- 两位开发者自行认领 A/B；技术分工已给出，无需预先指定姓名。
- v1 开始前用户确认普通博客验收结果。
- 云端发布前建立 Vercel、Neon、Blob 项目，并准备各环境凭据。
- v2 开始时选择实际支持 WebMCP 的浏览器/Agent，并记录验证版本。

这些是后续阶段的输入，不要求当前立即创建资源或开始 MCP 实现。
