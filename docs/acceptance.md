## 尚待用户或外部环境验收

- 用户确认普通博客的布局、配色和功能；未确认前不进入 v1 MCP。
- 没有 Vercel、Neon、Blob 资源；未验证线上访问、生产 Blob、云端备份恢复。
- 没有配置 Git 远程或推送。
- 浏览器验证使用本机 Chrome，不等于完整 Safari/Firefox 或真实手机兼容认证。

## 限制

- 历史版本恢复会回到草稿，保留当前归属和 slug；普通已发布文章保存仍立即生效。
- 媒体删除保护覆盖当前文章、页面和站点品牌图片；不保证所有历史版本的旧媒体永久保留。
- 模板非核心数据结构保留，后台导航隐藏，公开表单提交已禁用。
- Payload/pg 测试中有同连接并发查询弃用警告，当前版本测试通过；依赖升级时需回归。
- dev 与 build 不要同时写同一个 .next 目录。

## 复现

按 README 启动 Docker、迁移、seed:demo、build。浏览器用例读取本机 `.local/demo-accounts.md`；测试临时文章和图片在 finally 中清理。源码与公开文档不包含凭据。实际启动状态会随本机进程结束变化，按部署手册可重新启动。
