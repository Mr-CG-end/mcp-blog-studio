# 测试与验收计划

本文件规定 MCP Blog Studio 的测试范围、测试环境、命令以及验收通过准则。

## 1. 环境与命令

- 测试角色：admin、authorA、authorB、anonymous、disabledAuthor。
- 数据库测试仅在本机 `blog_studio` 或另行建立的隔离测试库运行，禁止连接生产。
- 用例创建随机前缀数据，结束后只清理自身创建的数据。
- 本地演示账号由 `pnpm seed:demo` 创建，明文凭据保存在 Git 忽略的 `.local`。

```sh
pnpm typecheck
pnpm lint
pnpm test:unit
pnpm test:int
pnpm build
# 已安装 Chromium 后，可运行仓库内浏览器回归脚本
pnpm test:e2e
```

不要让 `dev` 和 `build` 同时写同一个 `.next`。生产模式验证应先停开发服务，构建完成再 `pnpm start`。

## 2. v0 验收矩阵

| 编号 | 场景 | 预期 | 验证层 |
| --- | --- | --- | --- |
| T01 | 匿名创建用户、作者提交管理员角色 | 拒绝创建；角色不被提升 | API/数据库 |
| T02 | 匿名/作者 B 读取 A 的草稿及历史 | 不返回文档和版本内容 | 数据库 + REST/GraphQL |
| T03 | B 更新 A 的文章、A 伪造 owner | 越权失败，归属不变 | 数据库 |
| T04 | 发布、保存公开文章 | 公开内容立即反映保存结果 | 数据库 + 浏览器 |
| T05 | 下架、回收、恢复 | 公开入口不可见，恢复为草稿 | 数据库 + 浏览器 + 站点地图 |
| T06 | 两个请求提交同一旧 revision | 仅一个成功，另一个返回冲突 | 并发数据库测试 |
| T07 | 作者修改分类/站点/账号状态 | 被拒绝 | 数据库 |
| T08 | 图片上传、他人修改、引用中删除 | 合法上传成功；越权与引用删除失败 | 数据库 + 后台 |
| T09 | 超过 5 MB 或不支持格式 | 拒绝并显示明确提示 | 本地上传与独立 Blob 线上验证 |
| T10 | 日志查看与篡改 | 作者只看自己的日志，禁止修改 | 数据库 |
| T11 | 用户停用后用现有登录态访问 | 受保护读写失效 | API + 浏览器 |
| T12 | 首页、列表、详情、分类、搜索、关于、404 | 结构与内容正确；搜索可命中正文中文 | 浏览器 |
| T13 | 搜索零结果、错误分页、文章下架后访问 | 空态/404 可理解，不泄露内部错误 | API + 浏览器 |
| T14 | 390px 移动视口、桌面、主题切换 | 无横向溢出，可阅读与操作 | 浏览器 |
| T15 | 草稿预览 | 密钥 + 会话 + 文档权限共同满足才可读 | API + 浏览器 |
| T16 | 新数据库迁移和构建 | 从空库可运行；无生产 schema push | 迁移与构建 |
| T17 | 后台文章新建与保存 | 所有者自动设置，版本递增，富文本可用 | 真实后台 UI |
| T18 | 所有权转移、历史恢复 | 当前归属和版本访问不出现漏洞 | 专项回归，发布前完成 |

## 3. v1 验收矩阵

| 场景 | 必须验证 |
| --- | --- |
| 协议 | initialize、tools/list、tools/call、非法 method/schema、无状态重复连接 |
| 身份 | 无 key、假 key、撤销 key、停用用户、变更角色、多用户混用请求 |
| 查询 | 权限过滤、中文搜索、分页上限、草稿/回收站、不可猜测他人资源存在性 |
| 创建 | 默认草稿，owner 服务端指定，幂等 ID 并发重试只产生一篇 |
| 修改 | 部分更新、未知字段拒绝、旧 revision、不支持区块、已发布即时更新 |
| 状态 | 发布/下架/回收/恢复；非法状态拒绝；恢复绝不自动公开 |
| 转换 | 标题/列表/引用/代码/图片往返；未知节点、对齐与格式丢失保护 |
| 审计 | 成功、校验失败、权限失败、事务回滚后失败日志仍可追踪 |
| 错误 | 401 在 HTTP 层，业务错误 isError，requestId 可追踪且无敏感信息 |
| 客户端 | 真实 Codex 中执行完整脚本，不只用 mock transport 判定可用 |

### v1 演示脚本

1. A 用户创建个人密钥并配置 Codex，调用 get_current_user。
2. 查询分类和媒体，创建带标题、摘要、正文和封面的草稿。
3. 读取详情，拿最新 revision 修改，再发布；浏览器看到文章。
4. 直接修改已发布内容，确认网站更新。
5. B 用户尝试修改 A 的文章，操作失败且日志可追踪。
6. 模拟旧 revision 提交，返回冲突；重新读取再更新。
7. 下架、回收、恢复，确认恢复后为草稿。
8. 撤销 A 密钥，原连接无法继续调用。

## 4. v2 验收矩阵

- 目标浏览器/版本/试验条件写入记录；真实浏览器可发现工具。
- 不支持接口时页面照常运行，不加载失败遮挡普通功能。
- 搜索、分类、分页写入 URL，工具结果与页面内容一致。
- 打开文章仅跳本站，滚动目标确实存在。
- 后台编辑和预览使用当前会话，过期/停用/无权限时明确失败。
- 路由切换、重复挂载、刷新、后退、取消后无失效工具和重复注册。
- 网页脚本、HTML、日志中没有个人 MCP 明文密钥。
- 用 v1 发布新文章，再由 WebMCP 搜索、打开、滚动，录制一段可复现演示。

## 5. 发布签核

A 签核权限、数据完整性和迁移；B 签核协议/页面行为、演示和文档。双方共同确认失败场景，不使用“基本正常”代替缺失证据。

每次记录版本/提交、环境、执行时间、命令、结果、缺陷和限制。未验证项注明原因，不把未执行的 Playwright 脚本或尚未创建的云环境标记为通过。
